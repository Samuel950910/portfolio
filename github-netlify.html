Git、GitHub 與 Netlify 的學習

學習用 Git 管理網頁的修改紀錄，把個人網頁放上 GitHub，再讓 Netlify 自動部署。之後每次 git push，網站就會自動更新，不需要手動上傳檔案。

1. 設定 Git 身分

第一次使用 Git 時，先設定名字與 Email，之後每次提交都會記錄是誰做的修改。

git config --global user.name "你的名字"
git config --global user.email "你的 Email"

2. 在 GitHub 建立 repository

  1. 登入 GitHub，點右上角「+」→「New repository」。
  2. 名稱填 portfolio，不要勾選 README、.gitignore 或 license。
  3. 按「Create repository」。

3. 把網頁上傳到 GitHub

在網頁資料夾裡打開 Git Bash，輸入：

git init
git add .
git commit -m "第一版個人網頁"
git branch -M main
git remote add origin https://github.com/你的帳號/portfolio.git
git push -u origin main

第一次推送時會跳出 GitHub 登入視窗，登入後就會開始上傳。

4. 在 Netlify 連結 GitHub

  1. 到 Netlify 用 GitHub 帳號登入。
  2. 點「Add new site」→「Import an existing project」→ 選「GitHub」。
  3. 授權後選擇 portfolio repository。
  4. Branch 選 main；純 HTML 網頁的 Build command 留空，Publish directory 也留空（代表根目錄）。
  5. 按「Deploy」，等狀態變成 Published，就會得到一個網址。

5. 之後更新網站

修改檔案並存檔後，輸入三行指令：

git add .
git commit -m "說明這次改了什麼"
git push

Netlify 偵測到 GitHub 有新提交，會自動重新部署，在 Deploys 頁面可以看到每次更新的紀錄。

成果

  • 網頁原始碼放在 GitHub，有完整的修改紀錄。
  • 網站由 Netlify 自動部署，改完 push 就上線。
  • 流程固定為：改檔存檔 → 預覽 → 三行指令 → 看網站。
